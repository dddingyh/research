AI 芯片是怎么连成一台超级计算机的

一颗 GPU 的算力是有限的，真正的 AI 算力来自把成千上万颗芯片"焊"成一个整体。互联体系按距离分四个尺度逐级放大——晶粒之间、卡内、机柜内、机柜间。每跨一级，带宽下降、距离上升、介质从硅变成铜、再变成光。下面是可交互的逐层拆解。

LEVEL 01 — 最里层

板卡与封装结构：一颗"GPU"其实是一个微缩城市

LEVEL 02 — 一个机柜 = 一台 GPU

机柜内结构：GB200 NVL72 把 72 颗 GPU 变成"单卡"

机柜（Rack）内部是 NVIDIA 所谓的"超节点"。18 个计算托盘 + 9 个交换托盘，靠机柜背面的 NVLink Spine 铜背板（5000+ 根同轴铜缆）实现 72 颗 GPU 全互联（all-to-all）。这一级仍用铜而非光——因为距离短（<1m），铜更省电、更便宜、更可靠。点击托盘查看。

Scale-Up（纵向扩展 · 本柜内）

  • 协议：NVLink 5 / NVSwitch，每 GPU 1.8 TB/s
  • 介质：铜（NVLink Spine 同轴电缆背板）
  • 目标：让 72 颗 GPU 共享显存、当一颗用
  • 特点：低延迟、内存语义、全互联无阻塞

Scale-Out（横向扩展 · 跨柜）

  • 协议：InfiniBand 或 以太网 (Spectrum-X)
  • 介质：光（800G/1.6T 光模块）
  • 目标：把成百上千个机柜连成万卡集群
  • 特点：可路由、规模大、延迟更高

一句话区分：Scale-Up 用铜把几十颗卡焊成"一台大机器"，Scale-Out 用光把成千台机器连成"一个集群"。铜与光的分界线，差不多就在机柜的边缘。

LEVEL 03 — 机柜之间

机柜间连接：光纤织成的 Leaf-Spine 集群网络

出了机柜，铜走不远了，全部换成光模块 + 光纤。万卡集群普遍采用胖树 / Leaf-Spine 多层无阻塞拓扑，并按 GPU 的网卡做 Rail-Optimized（轨道优化）布线。每根光纤两端各插一个光模块——这就是光模块需求随 GPU 数量爆炸式增长的原因。点击节点查看。

LEVEL 04 — 把电变成光，再变回来

光模块内部结构：一枚硬币大小的电光转换器

光模块（光收发器 / Transceiver）插在交换机和网卡的笼子里，左侧是电接口（金手指），右侧是光接口（LC/MPO 光纤）。发送链路把电信号→驱动→激光器变成光；接收链路把光→探测器→TIA 放大变回电。核心三类芯片：DSP、激光器、探测器。点击各模块查看。

三条技术路线之争

  • 传统可插拔（EML + DSP）：当前主力，成熟可靠
  • 硅光 SiPh：光器件集成到硅芯片，利于 1.6T 上量，2026 占比有望过半
  • LPO 线性直驱：去掉模块内 DSP，靠交换机 SerDes，省电省成本

终极形态：CPO 共封装光学

  • 把光引擎直接封装进交换芯片旁边，电走线缩到最短
  • 大幅降功耗、提密度，应对 1.6T/3.2T 时代
  • 玩家：Broadcom、NVIDIA、Marvell、Ayar Labs 等
  • 代价：可维护性下降、生态尚不成熟

成本结构（典型可插拔模块 BOM）：DSP ≈ 30%，Driver + TIA ≈ 20%，激光器/光器件 + 封装 ≈ 50%。所以"激光器芯片"和"DSP"是两个最被资本关注的卡脖子环节。
